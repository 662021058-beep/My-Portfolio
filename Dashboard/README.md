# 📊 Executive Dashboard System

ระบบแดชบอร์ดสรุปผลและแสดงสถิติข้อมูลภาพรวม ช่วยให้เห็นข้อมูลสำคัญได้แบบ Real-time และวิเคราะห์ข้อมูลได้อย่างแม่นยำ

🌐 **Live Demo:** [ใส่ลิงก์เว็บถ้ามี เช่น https://your-dashboard.vercel.app]

---

## 📌 จุดประสงค์และการใช้งาน (Overview)

แดชบอร์ดนี้พัฒนาขึ้นเพื่อสรุปข้อมูลสำคัญ <ระบุ เช่น สรุปยอดขาย, จำนวนสินค้าคงเหลือ, สถิติการใช้งาน> ออกมาในรูปแบบอินเทอร์เฟซที่ใช้งานง่าย แสดงผลเป็นกราฟและตัวเลขสรุปเพื่อให้ผู้บริหารหรือทีมงานตัดสินใจได้รวดเร็วขึ้น
