🛠️ Tech Stack & Cloud Infrastructure

- Frontend: React.js, Vite, HTML5, CSS3 / Tailwind CSS
- Hosting: Deployed on Vercel
- Backend: Node.js, Express.js (RESTful APIs)
- Hosting: Deployed on Render
- Database: MySQL
- Cloud Database:Hosted on Clever Cloud
- Version Control: Git & GitHub

✨ Key Features 

1. 📦 Inventory Management: เพิ่ม แก้ไข และจัดการรายการยาในคลัง
2. 🔍 Smart Search & Filter: ค้นหารายการยาตามชื่อ หมวดหมู่ หรือประเภทได้อย่างรวดเร็ว
3. ⚠️ Expiration & Stock Alert: ระบบตรวจสอบเตือนเมื่อยาใกล้หมดอายุหรือสต็อกเหลือปริมารน้อย
4. 📊 Analytics Dashboard: สรุปยอดรวมจำนวนยาและสถานะคลังแบบ Real-time
5. 🔐 Security & Data Sanitization: มีการกรองและทำความสะอาดข้อมูลเพื่อป้องกันช่องโหว่
