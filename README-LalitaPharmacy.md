💊Lalita Pharmacy พัฒนาขึ้นเพื่อแก้ปัญหาการบริหารจัดการสต็อกยาในร้านขายยาหรือคลินิกขนาดเล็ก–กลาง ซึ่งมักประสบปัญหาการเช็กสต็อกยุ่งยาก ยาหมดอายุโดยไม่รู้ตัว หรือสินค้าขาดมือเนื่องจากไม่มีระบบแจ้งเตือน
ระบบนี้เป็น Web Application แบบ Full-Stack ที่ถูกออกแบบมาให้ทำงานได้เบา รวดเร็ว ปลอดภัย และเข้าถึงได้ง่ายผ่าน Web Browser โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม ช่วยให้เภสัชกรหรือเจ้าของร้านสามารถติดตาม ค้นหา และบริหารจัดการคลังยาได้แบบ Real-time จากทุกที่ทุกเวลา

📱 การใช้งานบนมือถือและทุกอุปกรณ์ (Responsive Support)
✅ รองรับการใช้งานบนมือถือและแท็บเล็ต ระบบถูกพัฒนาด้วยหลักการ Responsive Web Design ทำให้หน้าตาโปรแกรม (UI) ปรับเปลี่ยนขนาดให้เหมาะสมกับหน้าจอทุกชนิดโดยอัตโนมัติ


✨ ฟีเจอร์หลัก
1. 📦 Inventory Management: เพิ่ม แก้ไข และจัดการรายการยาในคลัง
2. 🔍 Smart Search & Filter: ค้นหารายการยาตามชื่อ หมวดหมู่ หรือประเภทได้อย่างรวดเร็ว
3. ⚠️ Expiration & Stock Alert: ระบบตรวจสอบเตือนเมื่อยาใกล้หมดอายุหรือสต็อกเหลือปริมารน้อย
4. 📊 Analytics Dashboard: สรุปยอดรวมจำนวนยาและสถานะคลังแบบ Real-time
5. 🔐 Security & Data Sanitization: มีการกรองและทำความสะอาดข้อมูลเพื่อป้องกันช่องโหว่
